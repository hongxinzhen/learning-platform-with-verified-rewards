# 墨芽 v0.9 · 统一角色图标、食物投喂与等级试玩

本轮已从单学生原型推进为本机服务端驱动的学校试用版。无云租金、短信或AI调用依赖；运行服务的电脑需要保持开机，异地家长访问尚未部署。

## 从这里开始

- 手机比例演示：http://127.0.0.1:4174/mobile-demo.html 。今日练习、统一伙伴小屋、二维背景曲线等级路线与立体背包已接入；在伙伴页点“新素材 试玩”查看真实机器人及浮岛，动作按钮随等级开放；成长手记→我的背包→收藏道具，可试五档宝箱和全屏领奖烟花。

- 正式学堂：双击「启动墨芽.cmd」，打开 http://localhost:4173/ ，第一次自行创建机构管理员。
- 手机同一可信Wi-Fi：关闭已有服务，双击「启动墨芽局域网.cmd」，手机访问窗口显示的IP地址。不会自动修改防火墙、路由器或开放公网。
- 独立演示：双击「启动墨芽演示.cmd」，打开 http://localhost:4174/ 。老师 `teacher_demo`，家长 `parent_demo`，共同密码 `MoyaDemo2026!`。样例数据在data/qa-2026-10-29，界面标识为演示，不能放真实资料。
- 使用说明：http://localhost:4173/school-help.html 。旧原型：http://localhost:4173/prototype.html ，旧浏览器档案保留，不自动迁入正式系统。

需要当前机器可用的Node.js24（现已安装）；启动后使用浏览器。项目为本机单进程试用，尚非公网生产部署或应用商店安装包。HTTP手机直接录音可能受限，可上传系统录音；统一小屋采用WebGL，不再要求WebGPU。真实儿童资料上线前需落实HTTPS与实际设备验证。

## 已有完整流程

管理员建老师、建班、分配权限、添加学生与家长绑定 → 老师发布每日/额外/作品任务 → 家长协助孩子拍照提交 → 基础经验和果实服务端结算 → 老师等级/文字/语音点评 → 孩子查看老师原声、个人作品对比、成长地图与成就 → 果实投喂独立培养伙伴。老师可登记实际出勤、记录特别鼓励原因；家长不能切换教师或给自己加经验。

同日主作业/额外作业各一个结算槽，防止通过重复发布/请求刷奖励。作品任务老师确认后发奖励、推进诗人作品成就。停止任务保留历史；密码可自改，管理员可重设家长密码。每日评级额外经验仍为C0/C+5/B10/B+15/A20/A+25；额外作业只记录评级，不重复发每日点评加成。

主人公门槛100+30×(L−1)，宠物Lv.1–100独立投喂；日常果实、连续奖励、补签、经验卡和升级礼包沿用既定规则。等级地图和结算共用levelPack。无付费加速、随机抽奖、公开等级排名、在线时长奖励或宠物饥饿惩罚。已选音效8C按钮/4A提交/6B升级/7B成就和进化继续保留。

3D伙伴共用一套WebGL小屋、镜头与场景内操作。保留原Jelly Baby软体网格和弹性求解器，新增Fox、柯基、海豹和RobotExpressive；切换只替换角色节点。未领养伙伴可预览，第二位伙伴仍在主人公Lv.25开放，不改变原奖励与领养上限。不同模型只展示各自支持的动作，动作等级由前后端共用配置校验。果冻支持原软体拖拽与专属装扮；其他伙伴保留各自原生动画，跳跃、设施互动包含程序动画。完整来源和许可见场景右下角说明；整合查看器按GPL-3.0-only提供源码。

## 数据与恢复

正式目录data/school，SQLite数据库+私有媒体文件；浏览器只管理会话，不是主要资料存储。API校验家长/班级权限、Origin/CSRF、提交与点评防重；账号密码加盐散列；媒体鉴权。

管理员页面可导出包含数据库与全部媒体的JSON备份（100MB内），恢复校验结构、关系与媒体hash后切换，保留旧目录回滚，注销所有旧会话。超出100MB请停止服务后复制整个数据目录，不要在运行中只复制SQLite主文件。备份含儿童作品/老师录音和账号散列，私密保存。

## v0.8验收范围（2026-10-30）

- 手绘魔晶、书册、原生动态流沙沙漏、宝箱、两种药瓶、护符、奖杯与两种徽章使用所选真实3D文件；列表图标是同模型的本地渲染缩略图，点开可旋转。奖杯不是徽章。
- 三款独立机器人、沙皮狗、黑豹已经接入同一场景。机器人Lv.3跳跃、Lv.10奔跑；狗Lv.5走动、Lv.10坐下。黑豹无原生行走动画，因此不伪装为可跑角色。机器人与狗支持场景旁方向键，移动限定小平台。
- 真实浮岛场景可试玩。还没有完整地图碰撞、导航与三阶段进化；小龙、BabyDragon、GIGI和皇冠尚未取得对应可用原文件，本轮未冒充接入。其它风景留待逐个验证。
- 普通奖励Cone金光、阶段奖励Trail烟花已用本地three.quarks实现，沿用用户选定音效，无BGM。宝箱五档为同模型材质变化，原作没有原生开箱动画。收藏馆未确定任务的道具仅展示，不擅自发放奖励。
- 所有学习数值、连续打卡与补签结算规则保持不变。61项自动检查通过；手机浏览器演示已检查，不等于Android/iOS真机性能验证。重模型仍需按手机性能进一步压缩。
- 对应源码、原作者署名、完整许可及构建说明在companion-viewer/licenses/moya-companion-source.zip，不包含学校数据库或账号。


## v0.9新增（2026-10-30）
- 12个伙伴图标由同一真实3D角色渲染，代替emoji。夜影修复损坏导出的三层辅助网格，保留原主体、甲胄和待机；所有长体型同时限定水平尺寸，切换时复位默认镜头。
- 四档投喂外观统一为汉堡/披萨/牛角包/蛋糕，仍沿用50/200/1000/3000伙伴XP。任务、每周课堂、礼包路线、背包、老师赠礼和3D投喂面板使用同一图标与名称。道具图标可点开实际3D模型和功能说明。
- 点击投喂会切到伙伴场景，食物靠近伙伴、享用后消失并出现经验反馈；过程不再被独立领奖窗口挡住。不把静态食品素材误称为原生食用动画。
- 演示空间“成长手记→等级试玩”支持任意1—10000级主人公预览，可查看礼包、路线和小屋设施，退出恢复真实等级；不更改实际XP、库存或领养资格。
- 改名卡使用Grab3D CC0封蜡信笺。新旧档首次各赠1张，之后每10级主人公礼包1张；改名1—12字、消耗1张，同名不消耗；服务器校验归属与库存，名字可跨重启保存。入口：背包改名卡，或伙伴头像→给伙伴取个名字。
- 主人公经验与经验册的图标详情分开说明，避免误把XP当成可使用的经验卡。既有学校数据不重置。
